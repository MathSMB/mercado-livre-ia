# mercado-livre-ia

Base de conhecimento de IA sobre os Procedimentos de Comercialização (PdCs) e as Regras de
Comercialização da CCEE (mercado livre de energia).

O desenvolvimento acontece por pull requests.

## Programas

- [`docrag/`](docrag/README.md): converte os PDFs (Docling + Marker), passa pelo portão de qualidade e gera os
  chunks com metadados para o SharePoint/Copilot Studio. Independente e reaproveitável em outros projetos.
